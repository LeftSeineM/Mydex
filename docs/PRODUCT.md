# Mydex 产品说明与讲述方式

版本：0.1.0 · 2026-10-21

## 一句话

Mydex 把微信里已经发生的交流变成可检索、可整理的个人与团队记忆，并让 AI 在授权会话中及时协作。

## 卖点一：从聊天流到行动清单

聊天每天产生，但决定和待办容易被新消息淹没。Mydex 基于本地已取得的聊天记录，按群、联系人、时间或问题寻找依据，生成回顾、事项梳理和待确认清单。

可以这样演示：选一个授权测试会话，输入“整理这周讨论、已决定事项和下一步”，展示记录范围、摘要及未确认项。对外描述为“基于本地记录的整理”，不要声称覆盖全部聊天或所有附件。

后续可以增加日报/周报：把相同整理流程交给调度器，固定时间生成，并按授权保存或发送。**当前版本已有手动整理和检索基础，通用定期整理仍是后续能力。**

## 卖点二：把 AI 放进已有沟通场景

团队不用把问题搬到另一个工具，在已授权群聊里 @ 助手，或通过指定联系人私聊发问。Mydex 获取当前会话的相关上下文，生成回答并送回同一会话；每个会话独立处理，避免串话。

可以这样演示：群里真实 @ 提出一个问题，展示回答；再由授权联系人私聊提出另一问题，确认不出现前一个群的私人内容。实发演示前核对当前账号、接收对象与发送许可。

## 建议故事结构

1. **问题：**信息留在聊天里，找不到结论，重复回答耗时。
2. **办法：**在本地已有聊天与模型之间建立受控连接。
3. **能力：**回顾过去的记录，回应当前的问题。
4. **可信依据：**会话隔离、记录范围、真实发送确认和失败暂停。
5. **下一步：**把手动整理扩展为可配置、可追溯的定期报告。

## 可以直接使用的介绍

> Mydex 是一个面向微信桌面端的本地 AI 助手方案。它有两个方向：把已获取的聊天记录整理成摘要、决定和待办；在授权群聊或私聊中，根据当前会话上下文回复问题。底层通过版本校验、账号绑定、本地只读记录视图和发送确认连接整个流程。现阶段已经具备记录检索、手动总结和会话回复的源码基础，后续计划增加统一的定期整理与报告投递功能。

以上描述区分了源码已有能力与后续计划；本次 GitHub 整理不等于重新完成真实微信端到端验收。
